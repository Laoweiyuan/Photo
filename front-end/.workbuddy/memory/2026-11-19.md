## photo/front-end 初始化（Vue3 + Naive UI 后台布局）
- 从空目录搭建 Vite 6 + Vue 3.5 + TS 项目，依赖：naive-ui、@vicons/ionicons5。
- 关键文件：`src/App.vue`（NConfigProvider + lightTheme + themeOverrides：主色 #1677ff、圆角 6px、zhCN locale、NMessageProvider）、`src/layouts/AdminLayout.vue`（NLayout + NLayoutSider 240/64 折叠、NMenu 五项、底部 NDivider + 用户入口 NDropdown）。
- 决策：tsconfig 不拆 tsconfig.node.json（vue-tsc 报 TS6310 referenced project may not disable emit），直接把 vite.config.ts 纳入主 tsconfig 并加 @types/node。
- 决策：折叠触发器用 NLayoutSider `show-trigger="arrow-circle"`（比 bar 更易发现）；用户下拉 placement 随折叠切换（展开 top-start / 折叠 right-start）。
- 决策：MenuOption.label 是 string | (()=>VNodeChild)，用于 NCard title 需做 typeof 收窄。
- 验证：`npm run build` 通过；playwright-cli 截图确认展开/折叠/下拉三态正常（静态资源放 public/avatar.svg、public/favicon.svg）。
